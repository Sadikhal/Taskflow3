## Features:

🎨 Modern UI with Tailwind CSS — Beautiful and consistent design using Tailwind and ShadCN UI.

📱 Fully Responsive — Seamless experience across all screen sizes and devices.

🔐 Advanced Authentication — Secure login and registration with JWT-based credential authentication.

✉️ OTP Verification via Email — Email-based OTP verification using Nodemailer.

🔁 Password Reset via Email — Reset password functionality by sending a secure link to the user's email.

📦 Task Management (CRUD) — Create, read, update, and delete tasks with ease.

🔄 Page Loading States — Smooth and informative page loading indicators.

📭 Empty State UI — Clean and user-friendly empty state design.

⚡ State Management with Zustand — Lightweight and scalable global state management.

### Cloning the repository

```shell
https://github.com/Sadikhal/Taskflow3.git
```


### Install packages

```shell
npm install
```

### Setup .env file in server


```js
MONGO_URL 
PORT 
JWT_KEY
ORIGIN 
NODE_ENV= "production"
SMPT_MAIL
SMPT_PASSWORD 
SMPT_PORT 
SMPT_HOST 
SMPT_EMAIL
```

### Setup .env file in frontend


```js
VITE_BASE_URL=
```


### Start the frontend

```shell
npm run dev
```
### Start the server

```shell
 node app.js
```
